# DeepMiCode 桌面端改造分析文档

> 生成日期：2026-06-02
> 对比对象：DeepMiCode v0.53.0 (`desktop/`) vs cc-haha v0.3.2 (`desktop/`)
> 参考项目：cc-haha-main（最新版）、claude-code-rust-working（Rust+egui）、CodeWhale-main（Rust+ratatui）

---

## 一、项目定位对比

| | DeepMiCode | cc-haha |
|---|---|---|
| **技术栈** | TypeScript + React 19 + Tauri 2 | TypeScript + React 19 + Tauri 2 |
| **UI 框架** | 自写 CSS（`styles.css`） | Tailwind CSS + lucide-react 图标 |
| **状态管理** | useState + localStorage（App.tsx 3300+ 行） | Zustand 分 store（App.tsx 30 行） |
| **后端通信** | Tauri RPC（`invoke`/`listen`） | 同 |
| **版本** | v0.53.0 | v0.3.2 |

## 三、代码架构对比

### 3.1 目录结构

**DeepMiCode（当前）**
```
desktop/src/
  App.tsx              ← 3300+ 行，所有状态+逻辑
  protocol.ts          ← 事件类型定义
  ui/                  ← 20+ 个组件平铺
    sidebar.tsx
    composer.tsx
    thread.tsx
    settings.tsx
    ...
```

**cc-haha 0.3.2**
```
desktop/src/
  App.tsx              ← 30 行，纯组合
  stores/              ← 20+ 个 Zustand store
    uiStore.ts
    settingsStore.ts
    sessionStore.ts
    chatStore.ts
    tabStore.ts
    workspacePanelStore.ts
    browserPanelStore.ts
    taskStore.ts
    pluginStore.ts
    adapterStore.ts
    ...
  components/
    layout/            ← 布局组件
      AppShell.tsx
      Sidebar.tsx
      TabBar.tsx
      TitleBar.tsx
      StatusBar.tsx
      WindowControls.tsx
      ContentRouter.tsx
    chat/              ← 聊天组件
      MessageList.tsx
      ChatInput.tsx
      AssistantMessage.tsx
      DiffViewer.tsx
      MermaidRenderer.tsx
      ...
    workspace/         ← 工作区面板
    browser/           ← 浏览器面板
    workbench/         ← 统一工作台
    controls/          ← 控件
    shared/            ← 通用组件
    skills/
    plugins/
    tasks/
    teams/
  hooks/               ← 自定义 hooks
    useKeyboardShortcuts.ts
    useMobileViewport.ts
    ...
  lib/                 ← 工具函数
  api/                 ← API 客户端
  i18n/                ← 国际化
  types/               ← 类型定义
  theme/               ← 主题
  pages/               ← 页面
```

### 3.2 App.tsx 行数对比

| | DeepMiCode | cc-haha 0.3.2 |
|---|---|---|
| **App.tsx** | ~3300 行 | ~30 行 |
| **状态变量数** | 20+ 个 useState | 0（全部在 store 中） |
| **localStorage 同步** | 每个 state 手动写 | Zustand persist 中间件 |

### 3.3 Store 数量
