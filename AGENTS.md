# deepmicode — agent quickstart

Node ≥22, ESM, TS 5.9+. DeepSeek-native coding agent with Mimo provider support.

## Commands

| Command | What |
|---------|------|
| `npm run dev` | Run CLI from source (`tsx src/cli/index.ts`) |
| `npm run chat` | Chat mode (`tsx src/cli/index.ts chat`) |
| `npm run build` | Build dashboard → tsup → copy vendor CSS + tree-sitter grammars |
| `npm run test` | Vitest (forks pool, 1 retry, no globals) |
| `npm run lint` | `biome check src tests` |
| `npm run typecheck` | `tsc --noEmit && tsc --noEmit -p dashboard` |
| `npm run verify` | build → lint → typecheck → test (pre-push gate) |

Pre-commit hooks: `lint` only. Pre-push: full `verify`.

## Entrypoints

- **Library API**: `src/index.ts` → `dist/index.js`
- **CLI binary**: `src/cli/index.ts` → `dist/cli/index.js` (fully bundled, `#!/usr/bin/env node`)
- **Desktop**: `desktop/src/main.tsx` (Tauri v2 + React, standalone npm project)
- **Dashboard**: `dashboard/` (Vite SPA, built separately via `npm run build:dashboard`)

## Provider abstraction

Two providers via `src/providers/factory.ts` (`createProvider()` / `detectProvider()`):
- **DeepSeek** — native `src/client.ts` (default)
- **Mimo** — `src/providers/mimo-client.ts`
Set via env: `DEEPSEEK_API_KEY`, `MIMO_API_KEY` (see `.env.example`). Config: `deepmicode config`.

## Key modules

| Module | Purpose |
|--------|---------|
| `src/loop.ts` | `CacheFirstLoop` — main agent loop (three-region context) |
| `src/context-manager.ts` | ImmutablePrefix + AppendOnlyLog + VolatileScratch |
| `src/code/edit-blocks.ts` | SEARCH/REPLACE edit system (byte-for-byte match required) |
| `src/repair/` | Tool-call repair pipeline (flatten, scavenge, storm, truncation) |
| `src/mcp/` | MCP client (stdio, SSE, Streamable HTTP transports) |
| `src/tools/` | 23+ tool definitions (filesystem, shell, web, subagent, plan, etc.) |
| `src/core/` | Event-log kernel (ports/adapters hexagonal architecture) |
| `src/config.ts` | Config system (1613 lines — use CLI `config` command to query) |

## Workspace packages

Three packages under `packages/`:
- `ink` — Custom Ink fork (React reconciler + Yoga layout for TUI). Local, `tsconfig` aliased as `ink`.
- `@reasonix/core-utils` — Shared utilities (compaction, tildeify, tool-kind, permissions, approval)
- `dsnix` — Published short CLI alias (`dmcode`), depends on `deepmicode`

`desktop/` and `dashboard/` are standalone npm projects (not workspace members).

Package manager: **npm** (CI uses `npm ci`). `pnpm-workspace.yaml` exists but is unused in CI.

## Conventions

- **Named exports only**, no `export default`. Library entry: `src/index.ts`.
- **Direct relative imports**, no barrel re-exports. `import type` for type-only.
- **Biome**: double quotes, semicolons always, trailing commas, 2-space indent, 100 width.
- **TypeScript**: `strict`, `noUncheckedIndexedAccess`, `noImplicitOverride`.
- **Vitest**: explicit `describe`/`it`/`expect` (no globals). Test files flat in `tests/` as `*.test.ts`.
- **JSX**: `.tsx` for Ink components, `jsx: "react"` in root tsconfig.
- **Comment policy** enforced by test (`tests/comment-policy.test.ts`).

## Gotchas

- `dist/` is generated by `tsup` — never hand-edit.
- `.deepmicode/semantic/` is auto-generated vector index — never hand-edit.
- Vitest uses **forks pool** (not threads) — native modules (tree-sitter WASM, tokenizer BPE) OOM on thread pool. `retry: 1` absorbs Windows scheduler hiccups.
- **SEARCH blocks require byte-for-byte match** in `edit-blocks.ts`. Trailing whitespace or wrong indent = reject.
- The `ink` package is a **local workspace fork** (`packages/ink/`). Changes affect all TUI rendering.
- `!benchmarks/tau-bench/transcripts/*.jsonl` are tracked in git (reference transcripts); all other `*.jsonl` is gitignored.
- Tauri APIs are **fully mocked** in `tests/mocks/` for unit tests (10 mock files).
